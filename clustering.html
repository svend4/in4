🔗 Объединение компьютеров в кластер для AI

Стандарты связи, софт, архитектуры — от потребительских до серверных. Февраль 2026.

📌 Суть проблемы: почему память не объединяется «просто так»

Когда у тебя 4 компьютера по 16 ГБ RAM, у тебя не 64 ГБ общей памяти. Каждый компьютер видит только свою память. Чтобы использовать память другого компьютера, нужно:

Компьютер A (16 ГБ) ──┐ │ какой-то канал связи Компьютер B (16 ГБ) ──┤ (Ethernet / Thunderbolt / InfiniBand) │ Компьютер C (16 ГБ) ──┤ ➜ Софт разбивает модель на части │ и раздаёт каждому компьютеру свой кусок Компьютер D (16 ГБ) ──┘ Проблема: скорость связи между компьютерами НАМНОГО медленнее, чем доступ к своей памяти. Своя RAM: 50 000–800 000 МБ/с (50–800 ГБ/с) Ethernet 1G: 125 МБ/с (в 400–6000× медленнее!) Ethernet 10G: 1 250 МБ/с Thunderbolt 4: 5 000 МБ/с (40 Гбит/с) Thunderbolt 5: 10 000 МБ/с (80 Гбит/с, до 120 в пике) RDMA (TB5): 10 000 МБ/с (без накладных расходов TCP) NVLink 5: 225 000 МБ/с (1 800 Гбит/с) — только NVIDIA InfiniBand: 50 000 МБ/с (400 Гбит/с) — серверы
Ключевой инсайт: При кластеризации узкое место — не вычислительная мощность, а bandwidth канала связи между узлами. Если канал медленный, добавление узлов ЗАМЕДЛЯЕТ inference, а не ускоряет!

RDMA (Remote Direct Memory Access) — технология, при которой данные передаются напрямую из памяти одного устройства в память другого, минуя CPU и операционную систему. Это снижает латентность в 100× по сравнению с обычным TCP/IP. Apple добавила RDMA через Thunderbolt 5 в macOS 26.2 (декабрь 2025) — это прорыв для потребительского сегмента.

🔧 Кластеризация PC / Мини-ПК

Внутри одного ПК: Multi-GPU

Метод Bandwidth Как работает Ограничения
PCIe 4.0 x16 ~32 ГБ/с Стандартный слот для GPU Каждый GPU видит только свой VRAM. Обмен через PCIe.
PCIe 5.0 x16 ~64 ГБ/с Новые платформы Intel/AMD То же. Нет объединения VRAM.
NVLink (потреб.) ~112 ГБ/с RTX 3090 поддерживала NVLink bridge ❌ Убрано в RTX 4090 и 5090!
NVLink (серверн.) 900–1800 ГБ/с A100, H100, B200 — объединяет VRAM Цена от $10 000+ за GPU
Важно: В потребительских GPU (RTX 40xx, 50xx) NVIDIA убрала NVLink. Два RTX 5090 в одном ПК НЕ объединят свои 32+32=64 ГБ VRAM. Каждый видит только свои 32 ГБ. Для LLM софт (vLLM, llama.cpp) может разбить модель на 2 GPU, но обмен идёт через PCIe — это медленнее NVLink в 5–50×.

🏆 Почему Apple побеждает в кластеризации (пока)

Преимущества Apple

1. Unified Memory Architecture — вся память доступна GPU. На PC 64 ГБ DDR5 — это просто RAM, GPU её «не видит» быстро.

2. RDMA через Thunderbolt 5 — c декабря 2025 Mac'и могут передавать данные напрямую в память друг друга, минуя TCP/IP. В мире PC такого нет на потребительском уровне.

3. EXO + MLX — софт, заточенный под Apple Silicon, с tensor parallel и автообнаружением. Настройка = запустить одну команду.

4. Энергоэффективность — 4 Mac Mini потребляют меньше, чем 1 RTX 4090.

Что может PC

1. Апгрейд RAM — на мини-ПК можно поставить 96 ГБ DDR5, на Mac память распаяна навсегда.

2. eGPU через OCuLink — можно подключить RTX 3090/4090 к мини-ПК. У Apple нет внешних GPU.

3. Цена RAM — 64 ГБ DDR5 стоит $100–150. На Mac за 64 ГБ unified нужно доплатить $400+.

4. Будущее: CXL — стандарт Compute Express Link (CXL 3.0) позволит объединять память между серверами. Пока не в потребительских ПК, но к 2027–2028 ожидается.

CXL (Compute Express Link) — это «забытый старый» ставший «новым». Стандарт на базе PCIe, который позволяет нескольким процессорам/GPU видеть общий пул памяти. CXL 3.0 (2024+) поддерживает memory pooling и sharing между узлами. Это потенциально уравняет шансы PC и Apple, но пока CXL — серверная технология стоимостью тысячи долларов.
